# Indian Village Tycoon v1.3

🌾 A free browser-based Indian farm tycoon game — no download needed.

**Play now:** https://indian-village-tycoon.vercel.app

## Features
- Harvest crops on contact — walk through fields to cut plants
- Full supply chain: crops → coop/buffalo → mithai shop → mandi
- 3 named customer orders with live countdown timers  
- Daily login streak with 7-day rewards
- Weather system — rain grows crops faster, clear sky raises prices
- Land expansion, machine slot upgrades, godown storage
- Workers automate harvesting and deposit to machines

## Tech
Pure HTML5 Canvas, vanilla JS, no assets, no build step.
Single `index.html` file — works on any device.

## Deploy
Drag `index.html` into [vercel.com](https://vercel.com) or run `vercel --prod`
